# Switch-Case Programs in C++

This folder contains my C++ homework solutions and practice programs focused on `switch-case` statements.

## 📚 Problems

### 01. Exiting an Infinite Loop

**File:** `01_infinite_loop.cpp`

Demonstrates three methods for exiting a loop containing a `switch` statement:
- Using a Boolean flag variable
- Using a `return` statement
- Using `break` outside the `switch` statement

### 02. Note Denomination Calculator

**File:** `02_note_denominations.cpp`

Calculates the number of currency notes required to make ₹1330 using denominations of ₹100, ₹50, ₹20, ₹10, and ₹1.

## 🛠️ Language
C++
