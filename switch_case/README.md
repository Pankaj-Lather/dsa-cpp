### 01. Exiting an Infinite Loop

**File:** `01_infinite_loop.cpp`

## Methods to Exit an Infinite Loop Containing a Switch

This program demonstrates three approaches:

1. **Flag variable:** Change a Boolean variable to `false` to terminate the loop.
2. **Return statement:** Use `return` to exit the function containing the loop.
3. **Break outside switch:** Check the exit condition after the switch and use `break` to terminate the outer loop.

### Key Concept
A `break` statement inside a `switch` exits only the switch statement. It does not automatically terminate the enclosing loop.
